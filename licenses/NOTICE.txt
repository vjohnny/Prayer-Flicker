VJPrayerFlicker-v3-java17.jar

This jar bundles the Kraken Prayer Flicker plugin with the published Kraken API 5.5.1
binary so it can be sideloaded in vanilla RuneLite on Java 17. It is not the trimmed
sideload. The trimmed jar, with only the modules [VJ]Prayer Flicker reaches, is
VJPrayerFlicker-v3.jar from shadedJarJava11. See NOTICE-java11.txt.

Kraken API is loaded from its own hooks.json resource. No hook names were rewritten.

Modifications (GNU GPL v3, section 5): the login package, the login hook class,
and the break-handler package are not included. They read the RuneLite credentials
file or exist only to call that code. GameHooks and HooksLoader in this jar are the
Java 11 builds from kraken-api-java11, which do not map or return the login hook
group. See kraken-api-5.5.1-java11.patch. The published ClickScheduler class is the
one from the 5.5.1 binary; the trimmed v3 jar does not include ClickScheduler.
hooks.json is the unmodified 5.5.1 resource, mapped for RuneLite 1.13.8 revision 243.
This jar still contains the published API's other classes and its bundled walker and
DPS resources. It does not load on a Java 11 JRE.
