VJPrayerFlicker-v2.jar

This jar bundles the Kraken Prayer Flicker plugin with Kraken API 5.5.1, compiled
for Java 11 (class file version 55), so it can be sideloaded in vanilla RuneLite
running on a Java 11 JRE. Kraken API is loaded from its own hooks.json resource.
No hook names were rewritten. hooks.json is the unmodified 5.5.1 resource,
mapped for RuneLite 1.13.8, game revision 243.

Modifications to Kraken API 5.5.1 (GNU GPL v3, section 5):
The Java sources are tag 5.5.1, vendored at kraken-api-java11/src,
compiled with javac --release 11 instead of the upstream Java 17 toolchain.
kraken-api-5.5.1-java11.patch records every change.

This jar does not contain Kraken's login package, the login hook class, or the
break-handler package. That code reads the RuneLite credentials file (session id,
character id, and display name) or exists only to call it. hooks.json is still the
unmodified 5.5.1 resource. GameHooks and HooksLoader no longer map or return the
login hook group. ClickScheduler still calls Client.getAccountHash(), through
reflection, so the class file does not name the Jagex interface that declares it.
No packet or interaction hook names were edited.
